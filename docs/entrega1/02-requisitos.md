# Requisitos

| **Requisito** | **Alcance previsto** |
| --- | --- |
| R1 · Gestión de usuarios | Registro, acceso, cierre de sesión y eliminación de la cuenta. |
| R2 · Gestión de lugares de interés | Alta por coordenadas o topónimo, consulta, eliminación y selección sobre mapa. |
| R3 · Gestión de vehículos | Alta, consulta, eliminación y modificación. |
| R4 · Gestión de rutas | Trayecto y métricas. Costes de combustible y electricidad. Calorías. Criterio. Guardar, consultar y eliminar. |
| R5 · Gestión de preferencias | Favoritos, modo/vehículo y criterio por defecto. |
| R6 · Persistencia | Recuperación tras cierre normal e interrupción involuntaria. |

Las historias se distribuyen en HU-01 a HU-04 para R1, HU-05 a HU-09 para R2, HU-10 a HU-13 para R3, HU-14 a HU-21 para R4, HU-22 a HU-24 para R5 y HU-25 a HU-26 para R6.

\subsection*{HU-01. Registrar una cuenta}

\textbf{Requisito} R1\par

\textbf{Historia} Como persona no registrada quiero crear una cuenta para utilizar los servicios de movilidad.\par

\subsubsection*{Reglas de dominio aplicables}

\textbf{RD-01} El correo electrónico debe estar normalizado.\par

\textbf{RD-02} El correo electrónico debe ser único.\par

\textbf{RD-03} El correo electrónico puede tener como máximo 254 caracteres.\par

\textbf{RD-04} El nombre debe tener entre 1 y 70 caracteres.\par

\textbf{RD-05} La contraseña debe tener entre 10 y 128 caracteres.\par

\textbf{RD-06} Una operación inválida no debe modificar el estado confirmado.\par

\clearpage\subsection*{HU-03. Cerrar sesión}

\textbf{Requisito} R1\par

\textbf{Historia} Como usuario autenticado quiero cerrar mi sesión para impedir el acceso posterior desde ella.\par

\subsubsection*{Reglas de dominio aplicables}

\textbf{RD-13} Un código de sesión inexistente o ya cerrado no permite consultar datos ni altera otras sesiones.\par

\textbf{RD-14} El cierre debe comprobarse con una consulta posterior que no dé acceso.\par
